# 富人信息差 · 小红书图文笔记 Skill

> 每日 7 条新闻速览 + 干货认知包，纯 PIL 离线生成，零外部依赖。

![三件套预览](assets/preview.png)

## 是什么

小红书「3 页图文笔记」自动化生成器：

| 页面 | 用途 | 视觉 |
|---|---|---|
| page1 (v1 米黄三列 / v2 砂糖橘3:1) | 当日 4 条新闻速览 | 信息密度拉满 · 表格化 |
| page2 (v1 米黄三列 / v2 砂糖橘3:1) | 当日 3 条新闻速览 | 同上 |
| page3 (认知加油包) | 7 条选 1 引申的干货 | 文字主导 · 纸感底纹 |

**适用场景**：金融/经济产业/科技类账号每日图文。设计目标 = 提升「收藏率」（page3 干货）+ 维持「完读率」（page1+page2 信息密度）。

## 5 分钟上手

```bash
# 1. 准备当天的 7 条新闻（覆盖 ≥5 类: 国际/社会/科技人文/民生/经济产业）
# 2. 编辑 templates 顶部 NEWS 数据
# 3. 跑

python generate.py        # 出 page1.png + page2.png (v1 米黄三列)
python generate_v2.py     # 出 page1_v2.png + page2_v2.png (v2 砂糖橘3:1)
python generate_page3.py  # 出 page3.png (认知加油包)
```

输出文件：`page1.png` / `page2.png` / `page1_v2.png` / `page2_v2.png` / `page3.png`，每个 1080×1440。

### v1/v2 与 page3 的区别

- **v1 / v2**：纯模板，复制到任意目录就能跑（`BASE_DIR = __file__` 通用路径）。改顶部 `NEWS` 列表即可。
- **page3**：含更多内容变量（CHAIN / SIGNAL_CARDS / TOOL_BOX / DATA_SOURCES / FOOTER），推荐 `cp` 到项目目录后改顶部内容常量 + `BASE_DIR` 为目标路径。

## 四条铁律（红线）

| 红线 | 含义 |
|---|---|
| **间接热点切入** | 7 条覆盖 ≥5 类（国际/社会/科技人文/民生/经济产业）。禁直接搜财经、禁 7 条全同质化 |
| **去领导人** | 不点中外元首/央行行长/美联储主席姓名。机构名保留 |
| **去国内军事** | 不写国内军事动作（演训/演习/国防部/战区） |
| **去个股** | page3 不出现具体上市公司/未上市公司全称，也不做公司评级/排序。改用行业结构数据（份额演变/集中度趋势/产业里程碑）。page1/page2 新闻可出现公司名，但避免「推荐/目标价」类表述 |
| **去政策模块** | 不出现政策类内容（含「政策落地」「新政施行」「政策工具」/具体补贴/减免/规划/方案等表述）。允许用市场反应/资金流向/价格异动间接呈现宏观调控效果。page3 §03 用通用方法论（波特五力/生命周期/杜邦三因子）替代政策工具箱 |

## 7 种解读句式（每条不重复）

| # | 句式 | 用法 |
|---|---|---|
| ① | 转折 | A 主张 → B 打脸 |
| ② | 判断 | 数字+结论（PMI→衰退） |
| ③ | 直陈 | 事实直说（大模型发布） |
| ④ | 场景 | 标志性事件（15年来首次） |
| ⑤ | 趋势 | 数字持续变化（单日涨3%） |
| ⑥ | 结论 | 场景落地结论（订单翻倍/客户破万） |
| ⑦ | 预测 | 趋势延伸意义（出海抢单/卡位窗口） |

**字数预算**：新闻事实 ≤42 字 · 信号解读 ≤10 字

## page3 干货维度选型

从 7 条里挑 1 条引申做 page3，提升收藏率：

| 维度 | 适用场景 | 例 |
|---|---|---|
| **产业链梳理** | 涉及产品/行业结构 | 存储芯片新闻 → 5 环节产业链（设备/材料/设计/制造/封测） |
| **关键指标解读** | 涉及经济数据 | PMI 新闻 → 制造业 vs 服务业 PMI 怎么看 |
| **历史对照** | 涉及标志性事件 | 历史 IPO → 历轮 IPO 估值与回报对照 |
| **产业地图** | 涉及区域/集群 | 大湾区外贸 → 9 市外贸排名与产业分工 |
| **工具拆解** | 涉及通用方法论 | 周期判断 → 波特五力/生命周期/杜邦三因子 |

**3 段标准结构**（工具表型·不点名公司·收藏向）：
1. **01 产业链/逻辑链** — 5 个环节，文字行 + 小编号
2. **02 关键数字怎么读** — 5 张速查卡，每卡含「指标名 + 阈值 + 标准值 + 作用」
3. **03 分析方法速查** — 3 件套速查，每条含「工具名 + 全称注解 + 适用场景 + 使用步骤 + 经典案例」

### page3 设计哲学：工具表型 > 行业回顾型

收藏率取决于「下次用得上」的概率：
- ❌ 回顾型（历程/时间线/集中度数字）— 看一眼就忘
- ✅ 工具表型（数字标尺 + 方法论速查）— 跨主题可复用，看到任何相关新闻都能直接套

**02 速查卡示例**（以存储芯片新闻引申）：
- 市场集中度 · TOP3 > 70% · 标准值：国际警戒线 75% · 测供应链垄断程度
- 国产化率 · 突破 10% · 标准值：替代拐点门槛 · 测国产替代进度
- 量产良率 · < 80% · 标准值：盈利线 85% · 测产能爬坡成熟度
- 资本开支增速 · 同比 > 30% · 标准值：周期顶 50% · 测行业扩产热度
- 价格走势 · 连降 3 个月 · 标准值：反转信号 · 测库存出清/反弹时机

**03 分析方法示例**（通用方法论·不涉及政策）：
- 波特五力「Porter's Five Forces」· 适用：判断行业赚钱难度 · 步骤：画 5 维度打分 · 案例：智能手机 5 维评分
- 生命周期「Industry Life Cycle」· 适用：判断赛道所处阶段 · 步骤：导入→成长→成熟→衰退 · 案例：新能源车卡成长后期
- 杜邦三因子「DuPont Identity」· 适用：拆解 ROE 来源 · 步骤：净利 × 周转 × 杠杆 · 案例：ROE 20% 的拆解

更多细节（含版式坐标、设计决策、CHANGELOG）见 [SKILL.md](SKILL.md)。

## 设计要点

### page1 / page2 双版本

| | v1 米黄三列 | v2 砂糖橘 3:1 |
|---|---|---|
| 适用 | 偏信息密度、表格感 | 偏阅读体验、横排 |
| 配色 | #FBF6E4 + #F08A24 | #FDEBD0 + #FF8232 |
| 字号 | 固定 26pt | 动态铺满（4条页为基准统一） |

### page3 设计哲学：图轻字重

- 文字占画面 ~70%
- 彩色筹码 ≤40px（编号 22px 圆、tier 18px 圆）
- 数字作 hero（42pt，如 25%/22%/14%）
- 段编号 01-04 红字强化目录感
- 撕纸细线分隔（sw=2，轻盈）
- 可选 AI 骨架底纹（`PAPER_BG` 配置路径）

### 标题写法

```python
NEWS = [
    # ① 国际 · 美伊霍尔木兹 — 转折（美方主张→伊朗打脸）
    (1, "美方称已完全控制霍尔木兹海峡,伊朗反驳称海峡仍关闭,不接受条件不会重开。",
     "央视新闻 2026-08-13",
     "说要开也开不了"),
    ...
]
```

每条 = `(序号, 新闻事实, 来源, 信号解读)`。序号 1-7，**每条用不同句式**（见上 7 种）。

### 7 类覆盖建议（≥5 类）

按合规红线 7 类覆盖是「**间接热点**」要求，避免直接搜财经。建议配比：

| 类 | 占比 | 内容 |
|---|---|---|
| **国际** | 1-2 条 | 大国博弈 / 能源 / 汇率 |
| **社会** | 1 条 | 民生事件 / 行业现象 |
| **科技人文** | 1-2 条 | 大模型 / 机器人 / 文化 |
| **民生** | 1 条 | 消费 / 教育 / 就业 |
| **经济产业** | 1-2 条 | 行业格局 / 资本流向（机构名保留，不点决策者姓名） |

**禁止直接搜财经**：财经搜索常带政策解读，规避；改用「产业」「格局」「资本流向」切入。

**v40 vs v39 核心差异**：

| 维度 | v39（已弃·注解太浅）| v40（当前生效·注解加粗）|
|------|------------------|---------------------|
| 注解字号 | 20pt | **22pt**（粗·可读）|

| 注解底色 | 细线分隔 | **浅杏底色块 (252,240,218) 圆角 10** + **左侧 4px 橙条 (220,120,40)** |

| NEWS 解析 | 旧 regex 收 4 字段 | **regex 加 `(?:\s*,\s*["\'](.+?)["\'])?` 可选第 5 字段** |

**4 重视觉锤为什么缺一不可**（v40 实战踩坑）：
- 0913 v19 用户当场打回"字太小太浅看不见"
- 22pt 单改字号不够 → 颜色必须深到 (170,70,15)
- 深橙字在白卡片上仍然偏淡 → 必须加描边 + 底色块双重对比
- 底色块 + 左侧色条 → 与白卡形成"独立注解区"视觉分层

**为什么 v30 regex 必须同步升级**：
- v19 加 term_note 时只改了 `draw_row`，没改 `v30_pitfall_check.py` 的 `parse_news_items`
- 旧 regex 收 4 字段 → term_note 被吞进 signal → 信号卡变成"信号卡正文 + term_note" → 含空格的"造芯片/导弹必需金属"被 regex 误判为 check_08 失败
- 铁律：升数据结构必同步升级 regex 解析（红线 ㉝）
